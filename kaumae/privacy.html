「かうまえ」プライバシーポリシー

最終更新日: 2026年6月12日

データの収集について

「かうまえ」は、ユーザーの個人情報を一切収集しません。アプリ内で作成された記録・設定はすべてお使いの端末内にのみ保存され、開発者のサーバーに送信されることはありません（開発者はサーバーを運用していません）。

トラッキングについて

本アプリは、トラッキングを行わず、広告 SDK・解析 SDK を含みません。

Claude API の利用について（任意機能）

本アプリの AI リサーチガイド機能は、ユーザー自身が取得した Anthropic 社の API キーを登録した場合にのみ動作します。このとき、登録した商品名・カテゴリ・予算・条件のテキストが、ガイド生成のために Anthropic 社の API（api.anthropic.com）へ直接送信されます。送信は開発者のサーバーを経由せず、開発者がその内容を取得することはありません。API キーは端末の Keychain にのみ保存されます。Anthropic 社によるデータの取り扱いは 同社のプライバシーポリシーに従います。

データの削除

アプリ内の「せってい」からすべてのデータを削除できます。アプリを削除すると、端末内のデータも削除されます。
