Verified Sources

  • Product Hunt: Official launch guide says makers submit by logging in and choosing Submit > New Product.
  • Uneed: Submit page states no account is needed to start; signup is requested after preview.
  • AlternativeTo: FAQ says users can add software via Suggest new application; new users must wait one week.
  • BetaList: Homepage exposes Submit Startup and the submit URL redirects to sign-in.
  • SaaSHub: SaaSHub lists a free submission workflow and a directory list for promoting products.
  • Startup Stash: Add Listing page exposes List A Product and Startup Stash contact information.
  • Microlaunch: Premium page describes product submission, 30-day exposure, feedback, and paid Pro Launch.
  • Indie Hackers Products: Products page is the Indie Hackers product database entry point.
  • Crunchbase: Crunchbase says registered and socially authenticated users can add profile pages.
  • SubmitJuice: Microlaunch listing describes a paid service for manual submission to many directories.
